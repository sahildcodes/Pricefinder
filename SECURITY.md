# Security policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository rather than opening a public issue with exploit details or sensitive information.

Include the affected route or file, reproduction steps, expected impact, and any suggested mitigation. Do not include real credentials, personal data, or harmful payloads beyond what is necessary to reproduce the issue safely.

This repository is an educational prototype and does not currently publish supported release branches or a formal response-time commitment.
